## [​](https://docs.replit.com/features/agent/overview\#what-is-replit-agent)  What is Replit Agent?

Agent is your creative partner. Agent takes your ideas, helps you refine them, and then makes them real. Unlike a chatbot that only answers questions, Agent takes action: it sets up your project, creates applications, checks its work, and fixes problems along the way.Describe what you want in everyday language. No code or technical knowledge required. Agent handles the rest, from planning to deployment.

## [​](https://docs.replit.com/features/agent/overview\#how-to-use-replit-agent)  How to use Replit Agent

### [​](https://docs.replit.com/features/agent/overview\#getting-started)  Getting started

1

Describe what you want

In the [Project Editor](https://docs.replit.com/learn/projects-and-artifacts/project-editor), just start chatting. Describe an app you want to build, ask a question, research a topic, or pull data from [connected services](https://docs.replit.com/features/agent/general-agent) like BigQuery, Slack, or Notion. There are no constraints. Replit Agent handles whatever you throw at it.

Plan

2

Choose what to build

Optionally, select a project type: web app, mobile app, slides, design, data visualization, and more. If you already described what you want in step 1, Agent figures out the right setup automatically.

Agent writes code, sets up infrastructure, and tests the result. Once you’re in your project, you can switch between [Agent modes](https://docs.replit.com/features/agent/overview#agent-modes) to control how it builds.

### [​](https://docs.replit.com/features/agent/overview\#plan-mode)  Plan mode

Enable Plan mode to brainstorm, ask questions, and map out your project before Agent changes any code or data. In Plan mode, Agent will:

- **Break down complex projects** into ordered task lists
- **Explore different approaches** and weigh trade-offs
- **Review and refine** before any code is written

Click “Plan” in the chat input — or simply ask Agent — to switch to Plan mode. Example: “Create a plan to build a project tracker for my team”

Plan

Agent creates an ordered task list you can review and refine. When you’re happy with the plan, approve it and Agent starts building.

### [​](https://docs.replit.com/features/agent/overview\#agent-modes)  Agent modes

Choose how Agent builds your project:

![Agent modes popover showing Free, Power, and Max modes with Power selected, a Primary model list, and an Effort slider](https://mintcdn.com/replit/bnB4dbrCOCU5_cPu/images/replitai/model-selector-power-mode.png?fit=max&auto=format&n=bnB4dbrCOCU5_cPu&q=85&s=6686cdd64af602f85031a38c12495fc0)

The Agent modes popover with Free, Power, and Max modes.

- **Free Mode**: No-cost everyday Agent work within your plan’s allowance. The Core and Pro allowances reset every five hours and have weekly limits. The Starter tier keeps its existing limits. Check [Usage](https://replit.com/settings/usage) in **Settings** to see your usage.
- **Auto**: Automatic model selection for paid work in Power or Max on Core and Pro.
- **Power**: A paid, mid-tier mode with powerful models at an affordable price.
- **Max**: A paid, top-tier mode with the best frontier models for the most demanding work.

If a request needs more capability than Free Mode, Agent may offer a paid **Allow once** option. Replit asks for confirmation before a paid action starts, and Agent returns to Free Mode afterward.

Tip: You can also enable **[Plan mode](https://docs.replit.com/features/agent/plan-mode)** to review and iterate on Agent’s plan before building begins.

## [​](https://docs.replit.com/features/agent/overview\#frequently-asked-questions)  Frequently asked questions

Do I need to know how to code?

No. Agent handles all the technical work — writing code, setting up infrastructure, configuring databases. You describe what you want in plain language and Agent builds it.

How does Auto differ from Free, Power, and Max?

**Free Mode** is no-cost everyday Agent work within your plan’s allowance. In Power or Max, **Auto** selects a model for each paid task. **Power** is a paid, mid-tier mode with powerful models at an affordable price. **Max** is the paid, top-tier mode for the most demanding work.Paid actions require confirmation before they start.

Can I build more than one thing in a project?

Yes. You can add web apps, mobile apps, slides, videos, and data visualizations to the [same project](https://docs.replit.com/features/projects-and-artifacts/artifacts#multiple-artifacts-in-one-project) — all sharing the same backend and data.

What happens if Agent makes a mistake?

Agent tests its own work on a regular basis. Agent also creates checkpoints as it works, so you can roll back to any previous state. You can also chat with Agent to describe what went wrong and it will fix the issue.
