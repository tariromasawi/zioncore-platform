### [​](https://docs.replit.com/updates/2026/10/30/changelog\#contribute-to-your-company-codebase-with-cloud-agents)  Contribute to your company codebase with Cloud Agents

Turn an idea into a tested code change, even if you’re not an engineer. Describe what should change, and a Replit Cloud Agent finds the relevant code, makes the change, tests it in your running app, and opens a GitHub pull request or GitLab merge request with screenshots and video.Your team sets up a shared development environment once. Changes run in isolated cloud sandboxes and follow your team’s contribution guidelines. Engineers review the changes and stay in control of what ships.![Replit displays a proposed heading change in the Changes pane beside the chat, with the linked pull request in Details.](https://mintcdn.com/replit/ZvLiuMLrojYoqf3I/images/code-contributions/push-result.jpg?fit=max&auto=format&n=ZvLiuMLrojYoqf3I&q=85&s=628442b1340c4cea26814d92b903fed9)Learn how to [contribute to your company’s codebase with Replit](https://docs.replit.com/build/code/code-with-replit).

## [​](https://docs.replit.com/updates/2026/10/30/changelog\#platform)  Platform

### [​](https://docs.replit.com/updates/2026/10/30/changelog\#message-and-create-chats-with-agent)  Message and create chats with Agent

You can now ask Agent to send a message to another chat or create a new chat, without copying and pasting messages or prompts yourself.Available to Pro and Enterprise users.

### [​](https://docs.replit.com/updates/2026/10/30/changelog\#gpt-6-1-terra-in-the-model-selector)  GPT-6.1 Terra in the model selector

You can now choose GPT-6.1 Terra from the model selector when building with Agent in Power Mode.Learn more about [choosing a model](https://docs.replit.com/features/agent/model-selector).
