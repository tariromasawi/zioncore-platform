## Comprehensive report enhancement

The green Measured card now contains the complete free dossier. All original measured lines remain. Its height is content-driven, text wraps, and a populated report spans the workbench width; the page scrolls normally rather than hiding content in a fixed-height report.

The previous quiet branch intentionally generated only three basic observations, which contributed to the impression that the report was cut off. It now retains those lines and adds actual RMS/digital-silence information, FFT bin spacing when known, temporal context and source/scope. Non-quiet reports also explain spectral contrast and zero-crossing descriptors.

The report contains eight expanded sections:

1. Measured evidence and coverage.
2. Acoustic intelligence: frequency versus pitch, harmonics/resonance, amplitude, rhythm/modulation clues, spectral changes; unavailable measurements stay unavailable.
3. Context-led personal reflection and user-reported feeling.
4. Environmental, animal, spiritual and celestial/unknown perspectives with advice. Animal-call references are structural analogies, not a validated species classifier.
5. Competing explanations and checks.
6. Practical recording and investigation actions.
7. Optional browser AI, clearly separate from measurements and labelled as a snapshot.
8. Free-processing boundary, limitations, £1/month Premium and existing credit/quote routes.

A 416.4-second session with six seconds of temporal feature context is explicitly distinguished from a continuous interpretation of the entire session. Quiet input does not establish either silence throughout that session or a spiritual source/absence.

### Browser AI activation

The app has no permission to switch on Chrome settings, install missing hardware support or grant a parent iframe's permission policy. It now explains those boundaries, provides a direct-tab option, a copyable `chrome://settings/ai` address, `chrome://on-device-internals` guidance, an official requirements link and a working availability recheck.

First-use download is explicitly consented and bounded to ten minutes; inference is separately bounded to ninety seconds. Cancellation remains available. The Prompt API is asked for schema-constrained JSON and output is validated. There is no paid cloud fallback.

Official reference checked: https://developer.chrome.com/docs/ai/prompt-api. Chrome's web Prompt API is documented for compatible desktop Chrome 148+, not iPhone/iPad/Android. Embedding can require the parent to delegate `language-model`.

### Investigation, models and privacy

- **Investigate further** exposes an actual question, instrument recommendation, controlled steps, confounders and possible outcomes.
- Seven discovery states can be recorded. Later states require supporting text and remain **user assessments**, not automatic scientific verification. Repetition and AI agreement never establish a source automatically.
- Default model: existing local signal processing plus deterministic reflection/research rules. No cloud AI request is made for these free readings.
- Optional model: **Gemini Nano via the browser Prompt API**, with explicit permission for model download and on-device text processing. Unsupported browsers retain all deterministic tools. Cancellation, timeout, output validation and session destruction are implemented; there is no paid/cloud fallback. A successful real model generation has **not** been verified here: the capture browser reports on-device AI disabled.
- Optional public API: NOAA planetary K-index, fetched only after a click, with timestamp/provenance/staleness, request timeout and range checks. No recording or listening context is included. Geomagnetic context is not an acoustic measurement or evidence of a reply.
- Listening context, feelings and raw audio are excluded from notebook records. The explicit research question and evidence are included. Local storage is unencrypted and browser-profile scoped. Report export includes context/self-report by explicit user action.
- The motto remains: **“ZionCore a product for those who understands life deeply”**.

## Models and free AI options

No external AI service is advertised as unlimited or guaranteed free. Provider free tiers can change, have quotas and require consent for audio disclosure. Existing paid Gemini/OpenAI orchestration and quote/reservation safeguards are preserved.

An optional future browser model could add broader audio-event candidates. For example, an AudioSet-trained AST model distributed through Transformers.js is a candidate to evaluate, not an installed classifier. Before adoption, verify the exact checkpoint's license, download size, supported runtime, mobile memory use and class-level false-positive/recall measurements. Offer an explicit model download and a deterministic fallback; call outputs candidates, not verified species or translations. Do not load large weights or transmit audio silently.

A small local language model is also an evaluation candidate for richer wording, not a reliable free connection on every phone. It needs device capability checks, bounded generation and output validation. It must not turn spiritual metaphor into measured evidence or make new provider charges without a quote.

## Commercial integration and preservation

The visitor can try meaningful local functions and then explore existing Premium benefits and separately credit-funded provider processing. The new panel links to the existing membership and wallet routes rather than inventing a parallel billing system.

Existing free acoustic encoding/decoding remains available. Requiring a subscription and credits for that previously free functionality would remove an established capability; it has not been silently imposed. New paid depth should use actual advanced benefits and approved quotes, not artificial restrictions or claims that membership includes unlimited provider work.
