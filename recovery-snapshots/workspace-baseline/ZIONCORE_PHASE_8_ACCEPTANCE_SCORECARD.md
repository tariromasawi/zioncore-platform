## Project-wide release gates

1. **Deterministic software behavior:** all required unit and emulator test cases for the changed journey pass; no safety or billing test is skipped to obtain a pass.
2. **Privacy:** zero cross-account successes in the rule test matrix; no raw audio or private devotional text is sent or stored without an explicit user action and clear notice.
3. **Cost integrity:** every paid operation is tied to one valid quote, one idempotent ledger result, and a recorded provider outcome; no production charge is used as a test.
4. **Evidence honesty:** source code, a 200 SPA fallback, or an unauthenticated 401 is not evidence of a complete signed-in customer journey.
5. **Production controls:** Firebase rules, App Check enforcement, production price changes, migrations, and publication require their respective verified access and approval gates.

## Current blockers to a full pass

- Live Firebase Authentication provider settings, production Firestore rules, App Check key/App ID matching, and valid token exchange are not verified.
- No authorized live Firebase project access through the configured service-account credential has been confirmed.
- No signed-in production owner journey, real model availability/quota check, Stripe test-mode checkout-to-entitlement flow, or device loopback recovery trial has been completed.
- The exact Git revision behind `zioncore.replit.app` remains unconfirmed.

This scorecard makes Phase 8 measurable; it does **not** mark any unverified production journey as passed or complete Firebase Task #2.
